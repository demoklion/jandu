CARDS Library Platform Design System

Two public tenders for the design system of a shared platform used by Czech academic libraries: one for the visual style, one for the coded design system.

Target 1/3

How do we buy a design system with public money so that it is open, accessible and outlives any one supplier, and so that every library can wear its own brand on it?

My role 2/3

The gist of it

I'm the design systems lead at the National Technical Library, in the CARDS project team, and the project manager for both tenders. Rather than design the system in-house, we split it into two public tenders, one for the visual style and one for the coded design system. Now that both are awarded, I'm the supplier's day-to-day contact: I run the syncs, review designs and implementation, facilitate critiques and oversee the user research.

More details

CARDS builds a shared platform for the libraries of the CARDS association. It has many apps and many member institutions, each with its own brand, so the design system had to be white-label from the start.

The first tender buys a digital visual style for NTK, tested with users in three variants, then a white-label version other libraries can rebrand, and a proof of concept on another member institution and two platform apps. It also asks for rules on what each library may change and what stays fixed.

The second tender buys the coded design system: components in plain HTML and CSS and in Vue.js, built from the Figma library with an automated token export, documented, released as versioned packages, and open source under an MIT-compatible licence, so no single supplier owns it.

Both require WCAG 2.1 AA. The design system needs an accessibility audit before handover and a governance model with clear roles for approving changes, and the visual style follows the methodology of the Czech government design system. Both tenders were awarded in September 2026 and the work is now under way.

Since the kickoff in September I have run two weekly syncs with the supplier, one for the visual style and one for the design system and its documentation. When the brand typeface turned out not to be licensed for the web, I proposed an open-licence replacement and implemented it in the code myself. Before the user test of the three visual style variants I gathered colleagues for a critique round, ranked their comments by priority and handed them to the supplier, and I prepared the test flow and recruited students to take part. Throughout, I keep the work aligned with the Czech government design system, whose components the new system builds on.

Before the tenders I built an in-house alpha of the design system on top of the government design system and tested how developers would install and use it. It was retired in October 2026, once the supplier's work took over.

Alongside the tenders I promote design and research inside the library, including research with students of the Prague University of Economics and Business.
