CARDS Library Platform Design System

Two public tenders for the design system of a shared platform used by Czech academic and research libraries: one for the visual style, one for the coded design system.

Target 1/3

How do we create a design system with public money so that it is open, accessible and outlives any one supplier, and so that every library that chooses to can wear its own brand on it?

My role 2/3

The gist of it

I'm the design systems lead at the National Technical Library in Prague's Dejvice Campus. In the CARDS project team I manage projects for design system of the new library platform and related public tenders. Rather than design the system just in-house, we added two public tenders, one for the visual style and one for the coded design system. I'm the supplier's day-to-day contact: I run the syncs, review designs and implementation, facilitate critiques and oversee the user research.

More details

CARDS builds a shared platform (PNG aka platforma nové generace) for the libraries of the CARDS association. It has many apps and tens of member institutions, many with their own brand, so the design system has to be white-labeled and have wide framework support.

The first tender buys a digital visual style for one of the institutions (NTK), tested with users. Then we derive a white-label version other libraries can rebrand, and a proof of concept on one other member institution, and some platform apps. We also define basic rules on what each library may change and what stays fixed.

The second tender buys the coded design system: components in plain HTML and CSS with webcomponents, and in Vue.js, built from the Figma library with an automated token export, documented, released as versioned packages, and open source under an MIT-compatible licence, so no single supplier owns it. We plan to add more frameworks in time.

Both tenders require WCAG 2.1 AA (but we watch the coming 3.0 too). The design system needs an accessibility audit before handover and a governance model with clear roles for approving changes, and the visual style follows the methodology of the Czech government gov.cz design system. Both tenders were awarded in September 2026 and the work is under way.

We meet the supplier weekly. Before the user test of the visual style variants we ran a critique round with colleagues and passed the comments on to the supplier, and I prepared the test flow and recruited the students. When our brand typeface turned out not to be licensed for the web, I proposed an open-licence one and put it into the code myself.

Before the tenders I built an in-house alpha on top of the gov.cz design system and tested how developers would install and use it. We retired it in October 2026, when the supplier took over.

Besides the tenders I try to spread design and research inside the library, for example with research done with students of the Prague University of Economics and Business.
