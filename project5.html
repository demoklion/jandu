Work

CARDS Library Platform Design System

Two public tenders for the design system of a shared platform used by Czech academic and research libraries: one for the visual style, one for the coded design system.

Target 1/3

How do we create a design system with public money so that it is open, accessible and outlives any one supplier, and so that every library that chooses to can wear its own brand on it?

My role 2/3

The gist of it

I'm the design systems lead at the National Technical Library in Prague. In the CARDS project I manage the design system of the new library platform and its two public tenders, one for the visual style and one for the coded design system. I'm the supplier's day-to-day contact: I run the syncs, review designs and implementation, facilitate critiques and oversee the user research.

More details

CARDS builds a shared platform (PNG, platforma nové generace) for tens of member libraries, many with their own brand, so the design system has to be white-label and work across many frameworks.

The visual style tender delivers a user-tested style for NTK, a white-label version others can rebrand, and basic rules on what each library may change. The design system tender delivers web components and Vue.js, tokens exported from Figma, documentation and versioned packages, open source so no single supplier owns it. Both require WCAG 2.1 AA and build on the gov.cz design system.

Before the tenders I built an in-house alpha on gov.cz and tested how developers would use it. Both tenders were awarded in September 2026 and the work is under way.

Artifacts 3/3

  • Both public tenders, from requirements to award
  • Software catalogue of about 40 platform apps, prioritised for the design system rollout
  • In-house design system alpha on gov.cz, with Figma libraries, prototypes, and testing by other member libraries of how they install and use it
  • Integration strategy: a theme for CMS sites, light CSS changes for vendor apps
  • Critique rounds and the user test flow for the visual style
  • The end result: a public open source repository anyone can use

Client: NTK - National Technical Library

Location: Prague

Project length: December 2023 – Present (CARDS runs through 2028)
