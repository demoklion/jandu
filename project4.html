Work

Charles University Design System

A design system for the renewal of the student information system at one of Europe's oldest universities

Target 1/3

How can we modernize a legacy Student Information System serving all faculties of a historic university, ensuring a modern, responsive, mobile-first user experience while fundamentally rethinking the system architecture beyond just cosmetic improvements?

My role 2/3

The gist of it

I built the design system for the university's student information system from nothing: the component library in Figma and its documentation in Notion. It became the shared foundation for a full renewal of the system, not just a new coat of paint.

More details

The work started as a modern, responsive, mobile-first interface for everyday student tasks: study plans, results and personal data. Along the way it became clear that a visual refresh alone would not fix the deeper problems of the legacy system, and the project grew into a complete renewal.

There was no design system to start from. I set up the component library, the design patterns for complex academic workflows, and the documentation in Notion, so designers and developers worked from one source of truth that could scale across the university's faculties.

The work balanced modern user expectations with the complex rules of academic administration, kept accessibility in mind, and supported both desktop and mobile use. I worked closely with developers and with the people who use the system every day.

Artifacts 3/3

  • Design system in Figma built from nothing: documented components for academic workflows, student data and course administration, each with anatomy, properties and spacing rules
  • Beta release of the new student portal: home page, responsive dashboard, study plans, results and personal data
  • Foundations as Figma variables: colour tokens for light and dark mode with contrast tests, plus spacing, border, radius and effect scales
  • Mobile-first responsive design patterns ensuring functionality across all device types for student accessibility
  • Design system documentation in Notion, written from scratch, as the guide for future development across faculties
  • Phased rollout plan, from the first beta to the complete system renewal
  • Feedback loop and beta testing with students

Client: Charles University (Univerzita Karlova)

Location: Prague

Project length: February 2024 – June 2025
